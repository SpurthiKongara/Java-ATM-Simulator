# ATM Banking System GUI

## Overview

The **ATM Banking System GUI** is a desktop-based banking application developed using **Java Swing**. The project simulates real ATM operations such as login authentication, balance checking, depositing money, withdrawing cash, transferring funds, and viewing transaction history through an interactive graphical user interface.

This project demonstrates the implementation of:

* Java GUI programming using Swing
* Event handling
* Object-Oriented Programming concepts
* Transaction management
* Basic banking operations

# Functionalities

## 1. Login Authentication

Users must enter a valid account number and PIN to access the banking system.

---

## 2. Check Balance

Displays the current available balance in the user account.

---

## 3. Deposit Money

Allows users to add money to their account balance.

---

## 4. Withdraw Money

Users can withdraw money if sufficient balance is available.

---

## 5. Fund Transfer

Transfers money from one account to another account.

---

## 6. Transaction History

Displays recent transactions along with timestamps.

---

## 7. Logout

Returns the user back to the login screen securely.
